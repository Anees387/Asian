ASIAN STORE — BASIC GITHUB PAGES WEBSITE

FILES
- index.html: webpage content
- style.css: layout and design
- script.js: product search and shopping cart

UPLOAD TO YOUR GITHUB REPOSITORY (ANDROID OR COMPUTER)
1. Download and extract asian_store_basic.zip.
2. Open https://github.com/Anees387/Asian
3. Tap/click Add file -> Upload files.
4. Upload index.html, style.css, script.js and README.txt.
   Upload the files themselves to the repository root, not a nested folder.
5. Commit changes.
6. Open repository Settings -> Pages.
7. Under Build and deployment, choose Deploy from a branch.
8. Select branch main and folder /(root), then Save.
9. Wait a few minutes and check the Pages section for the published URL.
   The expected project URL format is https://anees387.github.io/Asian/

IMPORTANT
This is a static demo website. The cart works in the current page but is not saved between visits.
Checkout is only a demo alert; no order is submitted and no payment is taken.
GitHub Pages cannot run Python/Flask, Node server code, or a SQLite database.
